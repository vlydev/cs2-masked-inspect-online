What is a CS2 masked inspect URL?

A masked inspect URL (also called a masked inspect link) is a self-contained CS2 item preview link that encodes all item data — float value, paint seed, paint index, def index, sticker IDs and wear, keychain IDs — directly inside the URL as a binary protobuf payload. Unlike classic S…A…D… Steam inspect links, masked links do not require a live connection to the Steam Game Coordinator to decode and can be parsed completely offline.

How to decode a masked inspect link

Paste any of the following formats into the input above and press Decode (or just paste — the decoder runs automatically):

  • Masked — csgo_econ_action_preview%20<hex> — pure hex protobuf blob, fully offline decodable.
  • Hybrid — S…A…D<hex> — classic prefix with hex proto after the D parameter.
  • steam:// — full Steam browser protocol inspect link in any of the above formats.

The decoder extracts the skin float (paint wear, 0–1), pattern (paint seed 0–999), weapon definition index, paint index, per-slot sticker wear, and keychain details, then renders the equivalent !gen code for use in CS2 inspect bots.

Inspect link format internals

The payload is a protobuf-encoded ItemPreviewData message optionally XOR-encrypted with a single key byte. A 4-byte CRC32 checksum is appended for integrity verification. The paint wear float is stored as a reinterpreted IEEE 754 uint32. This format was introduced by Valve to allow skin marketplaces and trading sites to embed full item metadata in a single shareable link without backend lookups.

Gen code format

A gen code (!gen) is a space-separated string used by CS2 inspect bots: 

!gen {defindex} {paintindex} {paintseed} {paintwear} [{s0_id} {s0_wear} … {s4_id} {s4_wear}]

Sticker slots are always padded to 5 pairs (0 0 for empty slots). Keychains follow after the sticker block when present. The decoder on this page generates the correct gen code from any supported inspect link format.
